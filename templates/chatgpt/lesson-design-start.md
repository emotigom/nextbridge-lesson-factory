# ChatGPT 교안 설계 시작 템플릿

새 교안을 clean-room으로 시작할 때 사용합니다.

```text
이번 채팅은 Nextbridge Lesson Factory 기준의 clean-room 교안 설계입니다.

교안 내용을 만들기 전에 반드시 먼저 수업 레퍼토리를 확정하세요.
`경험 먼저`를 기본값처럼 가정하지 마세요.

Factory deliveryProfile 후보:
- `experience-first`: 경험 → 비교/발견 → 학생의 말 → 개념에 이름 붙이기 → 다시 적용
- `guided-build`: 주제/맥락 → 필요한 이론 → 짧은 영상 또는 완성 예시 → 오늘 만들 것 설명 → 강사와 함께 실습 → 학생이 자기 것으로 바꾸기 → 결과 확인
- `explain-practice`: 설명/시연 → 연습 → 확인

도구를 사용하는 제작형 수업이라면 다음 두 가지를 Course Map 승인 전에 반드시 확정하세요.
1. 실제 학생이 사용할 핵심 도구
2. 학생이 수업 중 실제로 완성할 결과물 한 문장

`guided-build`에서는 설명과 실습이 한 번에 끝날 필요가 없습니다.
예: 설명 약 15분 → 실습 약 20분의 덩어리를 차시와 주제에 맞게 1~2회 반복할 수 있습니다.
분 단위는 고정 규칙이 아니라 현장 가이드입니다.

중요:
- 전문용어를 무조건 경험 뒤로 미루지 않습니다. 실습 직전에 꼭 필요한 이론은 짧고 정확하게 먼저 설명할 수 있습니다.
- 동영상이나 완성 예시는 구경용이 아니라 곧 이어질 실습의 목표 모습을 보여주는 용도로 사용합니다.
- `서비스를 기획해보세요`처럼 추상적인 산출물보다, 실제 도구에서 학생이 직접 만들고 실행하거나 조작할 결과물을 우선합니다.
- 강사가 학생과 같은 화면을 보며 따라 할 수 있는 guided practice를 CORE로 둡니다.
- 실습 뒤에는 숫자·조건·디자인·프롬프트·오브젝트 등 최소 한 가지를 학생이 자기 것으로 바꾸게 합니다.
- 인터넷이나 계정 문제가 생겨도 핵심 수업을 복구할 경로를 둡니다.

진행 순서:
1. 허용 입력/금지 입력 정리
2. deliveryProfile + practiceAnchor(tool, studentBuild) 제안
3. 제가 승인
4. 전체 차시 상위 구조만 설계
5. 제가 승인
6. 이후 한 차시씩 상세 설계
7. 전체 승인 뒤 Factory QA
8. 사람 승인 뒤 PPTX/실습도구 제작

아직 제가 deliveryProfile과 practiceAnchor를 승인하기 전에는 상세 차시를 만들지 마세요.
```
